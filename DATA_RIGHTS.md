# Dataset Rights and Redistribution

## Redistribution decision

Public redistribution of the OpenStack/Qt-derived data assets in this
reproducibility package is **not approved at this stage**.

The local provenance audit did not identify explicit evidence establishing
redistribution rights for these derived package assets. Therefore they must be
excluded from any public release until the relevant source-dataset rights are
independently verified.

## Public-release rule

The following may be prepared for public release independently of this decision:

- source code;
- configuration files;
- environment information;
- execution instructions;
- documentation that does not redistribute restricted or rights-unverified data.

Data-derived assets must not be publicly redistributed under the current redistribution policy.

## Reconstruction approach

A researcher should obtain the underlying source datasets from an authorized
source and reconstruct the required local assets using the documented project
pipeline rather than receiving the data-derived assets directly from this
package.

## Important scope note

A Creative Commons Attribution 4.0 license observed for a separate Zenodo
replication package does not establish redistribution rights for the
OpenStack/Qt-derived assets used here.
